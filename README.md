# 🏋️ Ficha de Treino

Divisão PPL + Upper + Lower com check de exercícios e progresso salvo localmente.

## Stack
- Nuxt 3
- Vue 3 (Composition API)
- TypeScript
- LocalStorage para persistência

## Rodar localmente

```bash
npm install
npm run dev
```

## Deploy na Vercel

Ver instruções no README ou conectar via dashboard da Vercel.
